Zero Hassle Pipeline

全链路自动化：从硬件唤醒到无感刷新

Next5h 深度整合 macOS 底层内核电源管理接口与官方 Codex CLI，让任务派发在深睡与锁屏状态下也能完美完成。

01

硬件 RTC 芯片定时唤醒

调用 macOS IOPMSchedulePowerEvent 内核接口，在任务到点前 60s 准时硬件叫醒 Mac，并申请阻止深睡断网断电。

02

Wi-Fi 网络自愈与握手

唤醒后，内置的 NetworkMonitor 自动追踪网络链路，确保 Wi-Fi 成功握手并检测官方模型缓存。

03

本地 Codex CLI 静默派发

直接调用官方 ChatGPT.app/.../codex CLI 原生执行，无需屏幕解锁与密码输入，锁屏下安全完成。

04

codex:// 免重启即时刷新

同步更新本地 session 会话索引，通过 codex://threads/<ID> 深度协议让运行中的窗口即时刷新。

Quick Installation

简单 3 步，轻松部署 Next5h

我们为不同偏好的开发者提供了灵活的安装方式，从一键脚本到源码编译，开箱即用。

使用 Swift Package Manager 原生 Release 编译模式，打包生成标准独立的 Next5h.app： 

# 1. 克隆项目仓库
git clone https://github.com/KhalilHsu/next5h.git
cd next5h

# 2. 执行一键构建打包脚本 (编译 Swift 二进制并构建 Next5h.app)
./build_app.sh

# 3. 运行并体验应用
open Next5h.app

💡 提示：如需安装至系统应用程序目录，可直接执行：cp -R Next5h.app /Applications/

复制以下单行命令粘贴到 macOS 终端，将自动克隆最新代码、编译 Release 版本并启动： 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/KhalilHsu/next5h/main/build_app.sh)"

如果本地已有项目构建产物，可直接通过 Finder 或终端唤起已打包好的 Next5h.app： 

# 直接启动根目录下的编译交付物
open Next5h.app

# 检查 Next5h 进程是否常驻
pgrep -fl Next5h
